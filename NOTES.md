# NOTES — architecture & decisions log

Running log of how this project is built and why. Newest decisions at the bottom of each section.

## Core architecture

- **Coordinate space**: local meters, origin at the Central Plaza (hub) center
  (≈ 33.8127, −117.9190). +X = east, −Z = north. Every config file (lands,
  stars, landmarks) uses this one space, all derived from the OSM bake.
- **Engine/world separation**: `src/engine/` knows nothing about Disneyland
  (renderer, controls, day/night, loop); `src/world/` builds the park;
  `src/systems/` are gameplay services (zones, audio, crowds, hunt, guide);
  `src/config/` is the user-editable surface; `src/ui/` is plain DOM/CSS.
- **Events**: systems talk to the HUD through a tiny typed `Emitter`
  (`src/systems/events.ts`) — no framework, no coupling.

## Lighting (the big architectural rule)

- **Zero decorative point lights.** Every window, string light, lantern, and
  castle trim is an *emissive material* registered in
  `src/engine/emissive.ts`; bloom (in the composer) turns emissive pixels
  into glow. Real lights: 1 directional sun/moon + 1 hemisphere + at most a
  few accents later. This is what makes night at crowd-level-10 affordable.
- Day/night is one scalar blend (0..1) across a `LightingPreset` struct in
  `src/engine/dayNight.ts` — sky, fog, sun, hemisphere, bloom intensity,
  emissive boost — lerped with smoothstep over 4 s.
- Tone mapping is ACES in the composer (`ToneMappingEffect`), renderer tone
  mapping off. Post chain: Render → N8AO → (Bloom, Vignette, ToneMapping, SMAA).
- Gotcha found in stage 1: materials register with the emissive registry
  *after* the initial preset applies, so `registerEmissive` must apply the
  current blend immediately (fixed).

## Verification harness

- `npm run verify` boots Vite + headless Chromium (Playwright), captures
  every viewpoint in `scripts/viewpoints.json` in both day and night to
  `verify/`, and asserts a placeholder MP3 decodes. Dev URL params
  (`?cam=x,y,z,yaw,pitch&time=night&freeze=1&seed=42&hud=0`) bypass pointer
  lock for deterministic captures. Camera yaw convention: yaw 0 faces −Z
  (north), degrees, YXZ order.
- The page sets `window.__PARK_READY__` after 3 rendered frames.

## Audio

- Zone-based crossfade (1.5 s), driven by `src/config/audio.ts`. Silent
  placeholder MP3s are generated by `scripts/gen-silent-audio.mjs` (ffmpeg
  when present, hand-built MPEG-1 Layer III silent frames otherwise) and
  committed in `public/audio/`.
- AudioContext unlock + pointer lock share the single "click to enter"
  gesture (browser autoplay policy).
